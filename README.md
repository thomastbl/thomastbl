<table width="100%">

    <td width="33%" valign="top">
      <h4>⚖️ Rigor scales with risk</h4>
      <p>A typo just gets fixed. A feature runs the full loop. A change that's hard to undo starts with an ADR. Process is a tool, not a ritual.</p>
    </td>
    <td width="33%" valign="top">
      <h4>📐 Spec before code</h4>
      <p>A short vision and a roadmap with small milestones. ADRs only for the decisions that are expensive to reverse.</p>
    </td>
    <td width="33%" valign="top">
      <h4>🗺️ Plan & tests first, when it counts</h4>
      <p>On real features, an agent explores the code and writes a plan I approve, then failing tests it isn't allowed to touch, then the code.</p>
    </td>
  </tr>
  <tr>
    <td width="33%" valign="top">
      <h4>👀 Agents check their own work</h4>
      <p>Through MCP they run the game or app, read the logs and fix what's wrong. "Done" comes with proof, and with what couldn't be verified.</p>
    </td>
    <td width="33%" valign="top">
      <h4>🔍 Human in the loop</h4>
      <p>I own the vision, the product calls and the final review. Agents propose, build and push back once if they disagree. I decide.</p>
    </td>
    <td width="33%" valign="top">
      <h4>🌱 Process grows from real pain</h4>
      <p>Rules are added when a problem repeats, and removed when they stop paying off. Checks live in hooks, methods load on demand as skills, <code>CLAUDE.md</code> stays short.</p>
    </td>
  </tr>
</table>
